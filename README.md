# Cyber Wars Website

This repository hosts the Cyber Wars retro arcade game using GitHub Pages.

- `index.html` is the public homepage.
- `game.html` is the playable game.

## Enable GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the Pages deployment to finish.

## Update the game
Replace `game.html` with the newest Cyber Wars HTML file and commit the change to the main branch. The public website keeps the same address and displays the updated game.

Expected site address: https://363418013-dotcom.github.io/cyberwarsgame/

Google search indexing is controlled by Google and is not guaranteed. After publishing, submit the site in Google Search Console.
